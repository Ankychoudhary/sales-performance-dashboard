# Sales Performance Dashboard

This project analyzes sales performance using Power BI.

The dashboard provides insights into product-level profitability, category performance, and overall sales metrics.

## Key Metrics
- Total Sales: 1.02M
- Total Profit: 49.4K
- Total Quantity Sold: 5K

## Key Insights
- Storage Drawer generated the highest profit.
- Sales are distributed across multiple product categories.
- The dashboard helps identify top-performing products and profit contributors.

## Tools Used
- Power BI
- Excel
- Data Visualization
